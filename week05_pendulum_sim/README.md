## 实验结果与心得

意图设计思考
1. 意图设计思考
【思考⼿记】：在生成程序时采用ROCA格式，可以减少AI幻觉，减少迭代次数，加快AI生成效率。
创建纯净工作区，防止读取并修改不必要的文件。
2. 报错⾃愈思考
【思考⼿记】：将报错后生成的文档红字交给AI，AI可以快速找到该红字所对应的代码错误及其所在位置，高效且错误少，可以节省大量用于检查的人力。
3. ⼈机协同哲学反思
【思考⼿记】：AI可以依据我的要求生成对应的代码和文本，但需要我提出尽可能准确的自然语言要求约束AI生成内容，并依据产物不断提出更进一步的要求以逐渐达到满意的程度。
